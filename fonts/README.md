# Bundled font

`NotoSans-Variable.ttf` is the quote-card renderer's bundled text font. It was
downloaded from the
[Google Fonts Noto Sans directory](https://github.com/google/fonts/tree/main/ofl/notosans)
on 2026-08-01.

- Source file: `NotoSans[wdth,wght].ttf`
- SHA-256: `BFB7BB691513F12E734DC346C03A03F784912432D7E3FA8E56EFCF906FE86B3D`
- License: SIL Open Font License 1.1; see [OFL.txt](OFL.txt)

Keep the font in this directory so local Python runs and Docker deployments
render Vietnamese quote cards identically without relying on system fonts.
